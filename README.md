# Quiz Management System

A console-based Quiz Management System developed using the C programming language. This project allows students to attempt subject-wise quizzes and enables administrators to view student records.

## Features

- **User Panel:** Students can enter their name and roll number.
- **Subject Selection:** Choose from Maths, English, and Science.
- **Interactive Quiz:** Each subject contains 5 multiple-choice questions.
- **Automatic Scoring:** Calculates the student's score out of 5.
- **Admin Panel:** Password-protected administrator access.
- **File Handling:** Saves student information and quiz results in `students.txt`.
- **Student Records:** Admin can view all previously saved results.

## Technologies Used

- C Programming Language
- Structures
- Functions
- Pointers
- Arrays and Strings
- File Handling
- Conditional Statements and Loops

## How to Run

1. Clone this repository.
2. Open the project in a C compiler or IDE.
3. Compile the source file:

```bash
gcc main.c -o quiz
```

4. Run the program:

```bash
./quiz
```
